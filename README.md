# 🚀 Mr SMM Pannels

A modern Social Media Marketing (SMM) Panel for managing social media services, customer orders, balances, payments, and order tracking.

## 🌐 Live Website

**Customer Panel:**
https://mrsmmpannels.github.io/MrSMMPannels/

**Admin Panel:**
https://mrsmmpannels.github.io/MrSMMPannels/admin.html

> 🔐 The Admin Panel is intended for authorized administrators only.

## ✨ Features

* 👤 Customer Registration & Login
* 📊 Customer Dashboard
* 🛒 New Order System
* 📦 My Orders & Order Tracking
* 💰 Balance Management
* 💳 Payment Request System
* 🧾 Payment Proof Upload
* 🔔 Notifications
* 👤 Customer Profile
* 📜 Balance & Transaction History
* 🎧 Customer Support
* 🔎 Order Search & Filtering
* 🔐 Admin Order Management
* 📱 Social Media Services

## 📱 Supported Platforms

Main system components include:

* Customer profiles
* Orders
* Payment requests
* Payment proof storage
* Authentication
* Order status management
